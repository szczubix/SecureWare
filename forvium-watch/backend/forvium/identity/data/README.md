# common-passwords.txt.gz

Hasła z wycieków, które odrzuca polityka haseł (`forvium/identity/passwords.py`).

Źródło: `100k-most-used-passwords-NCSC.txt` z [SecLists](https://github.com/danielmiessler/SecLists)
(licencja MIT; lista opublikowana przez UK NCSC na podstawie danych Have I Been Pwned).
Zachowano wpisy od 8 znaków, zamienione na małe litery i posortowane.

Pełną bazę Pwned Passwords (skróty SHA-1) można podłączyć offline zmienną
`FORVIUM_BREACHED_PASSWORDS_FILE` (patrz README projektu).
